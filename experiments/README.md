# Results

Generated by:

```bash
python -m skillevo experiment --seeds 0,1,2 --output experiments
python -m skillevo report
```

- `results.json` — task-level records for every method, gate, pair, stream, and
  ablation, plus the cross-seed aggregate.
- `risk_coverage.json` — risk-coverage curves and coverage at fixed risk.
- `REPORT.md` — generated tables and figure links.
- `tables/` — CSV versions of the main tables.
- `figures/` — SVG figures used by the report.

The run uses three seeds, 70 source training tasks per seed, 42 target test
tasks per seed, and a library of about 20 skills. Total runtime is about 5.5
minutes on a laptop CPU. The JSON is the source of truth for the report.
