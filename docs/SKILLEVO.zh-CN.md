# SkillEvo 中文说明

SkillEvo 是一个面向**工具型智能体**的校准技能选择与分层经验记忆研究模块，并以时空任务作为 case study。基准会生成小尺寸多波段遥感场景，智能体组合遥感算子完成任务，全部实验在 CPU 上运行，不需要 LLM 或 GPU。

## 研究问题

1. 给定从历史任务中归纳出的技能库，一个小型、经过校准的判别器能否比“描述向量相似度”更准确地判断某个技能能否复用到新任务？
2. 两层经验记忆（短期 episode + 长期压缩经验）能否在保持任务成功率的同时，大幅降低存储，并改善复用概率的校准？
3. 在目标任务的少量 probe 上估计的迁移分数，能否自动隔离不可迁移技能，降低负迁移？

## 快速运行

```bash
python -m skillevo experiment --seeds 0,1,2 --output experiments
python -m skillevo report
```

第一条命令生成 `experiments/results.json` 和 CSV 表格；第二条生成 `REPORT.md` 与 SVG 图。提交的实验在普通笔记本 CPU 上约 5.5 分钟。

## 基准

每个任务是 32×32 像素、6 波段的场景，带隐藏真值。共 7 个任务族：

| 任务族 | 输入 | 目标 |
|---|---|---|
| `landcover` | 单时相 | 6 类土地覆盖（OA） |
| `crop` | 单时相 | 作物/非作物（F1） |
| `water` | 单时相 | 水体（F1） |
| `flood` | 单时相 | 灾后水体（F1） |
| `change` | 双时相 | 任意变化（F1） |
| `urban` | 双时相 | 新增建设用地（F1） |
| `burn` | 双时相 | 火烧迹地（F1） |

场景包含类别光谱、空间连续地物、农田、季节光照、传感器增益、噪声、云污染，以及受控的城市扩张、森林砍伐、轮作、洪水、火烧等变化。同一任务配置始终生成同一场景。

一个**技能**是一段完整的分析配方，由 `index`、`temporal_diff`、`spectral_change`、`threshold`、`classify`、`smooth`、`remove_small`、`fill_holes` 等原语组成。技能库从源任务的参考解归纳，并按规范化签名去重；一次实验通常有约 20 个不同技能。

## 方法

### 校准的技能选择器

对候选技能 `s` 和新任务 `t`，估计 `P(reuse(s,t)=1)`。特征分三组：

- **检索**：哈希描述向量的余弦相似度及候选排名；
- **兼容性**：目标匹配、来源任务族匹配、输入类型匹配、光谱机制匹配、波段覆盖、自适应参数、算子成本；
- **经验（可选）**：Beta 平滑的成功率/效用、新近度、覆盖度、重复率、新颖度、任务族条件成功率。默认选择器使用结构特征；记忆变体用于流式实验和消融。

模型是小规模 L2 正则逻辑回归（IRLS 拟合），再用源任务验证集做后校准：temperature scaling 或 isotonic regression。默认选择器使用结构特征 + isotonic；记忆变体和特征消融单独报告。

### 分层经验记忆

- **短期记忆**：保留最近 24 条 episode 原文；
- **长期记忆**：有界容量的整合记录。`tiered` 截断旧记录，`tiered_dedup` 合并重复 `(skill, family, target, success, utility bucket)`，`full` 再剪枝低效用记录。

流式实验采用 prequential 方式：先选技能，再观察结果并写入记忆，避免测试标签泄漏。

### 跨任务迁移诊断

对每个技能和目标任务族，在 8 个目标开发任务上做 probe，得到效用增量；用 Beta-二项后验与结构兼容性先验组合：

```
compatibility = 0.30 * target_match + 0.15 * family_match
              + 0.15 * input_match + 0.30 * mechanism_match
              + 0.10 * band_coverage
score = 0.60 * compatibility + 0.40 * normalized_probe_utility
```

当兼容性低且 probe 效用弱时标记 `blocked`；结构/经验一致或经验很强时标记 `transferable`；其余为 `uncertain`。门控在重排前移除 blocked 技能，并降低 uncertain 权重。

## 实验协议

- 3 个随机种子。
- 每个种子：70 个源训练任务、28 个源验证任务、56 个目标开发任务、42 个目标测试任务、56 个流式任务。
- 候选池：描述向量 top-8。
- 主表使用 top-1；预算版本最多重试 3 个候选。
- 成功率阈值在最终实验前固定。
- 95% CI 用 2,000 次任务级 bootstrap；成功率的配对检验用精确 McNemar；分数的配对检验用 5,000 次符号翻转置换。

## 主要结果

| 方法 | 成功率 | 任务分数 | AUROC | Brier | ECE |
|---|---:|---:|---:|---:|---:|
| 随机候选 | 0.349 | 0.389 | 0.495 | 0.334 | 0.284 |
| 描述向量检索 | 0.500 | 0.505 | 0.666 | 0.233 | 0.152 |
| 频率先验 | 0.540 | 0.524 | 0.509 | 0.246 | 0.138 |
| 逻辑回归（未校准） | 0.683 | 0.632 | 0.842 | 0.164 | 0.120 |
| + temperature | 0.683 | 0.632 | 0.842 | 0.165 | 0.105 |
| + isotonic | 0.675 | 0.629 | 0.842 | 0.156 | 0.063 |
| + 目标开发集校准 | 0.683 | 0.632 | 0.841 | 0.157 | 0.087 |
| 预算重试（3 次） | 0.746 | 0.701 | 0.842 | 0.156 | 0.063 |
| Oracle 候选上界 | 0.802 | 0.753 | - | - | - |

相比描述向量检索，校准选择器把 top-1 成功率提高 17.5 个百分点（McNemar p<0.001），任务分数提高 0.124（置换 p=0.0002），AUROC 从 0.666 提到 0.842，Brier 从 0.233 降到 0.156，ECE 从 0.120 降到 0.063。

迁移门控把成功率从 0.675 提到 0.698，负迁移率从 0.056 降到 0.048。迁移矩阵呈现清晰块结构：土地覆盖分类器对水体/洪水迁移强（probe utility 0.90/0.92），对变化/城市/火烧几乎不迁移（0.03/0.05/0.08）；水体技能迁移到洪水（0.60），但反向到变化为负（−0.11）；变化与火烧检测器互相迁移（0.28/0.23）。

记忆流实验中，成功率基本持平（无记忆 0.774，分层 0.774，full 0.774），但校准显著改善：ECE 从 0.232 降到 0.120（full）/0.113（flat）。full 只保留 109 条记录 / 9,987 字符，而 flat 保留 616 条 / 57,315 字符，约 5.7 倍压缩。

## 解释与诚实结论

特征消融显示：结构兼容性特征集是默认选择器，达到 0.675 的 top-1 成功率；加入历史结果特征后静态成功率降到 0.611。在这个基准里，结构兼容性携带了大部分选择信号；历史特征主要改善流式场景的校准，并支撑记忆模块。迁移门控的价值在于把兼容性和 probe 证据变成显式、可审计的决策，而不是单纯追求 top-1。

合成场景是**受控诊断基准**，不能替代真实遥感评测。它的价值在于真值、变化类型、光谱机制和场景难度可控；不能据此声称方法会提升生产级土地覆盖/变化检测系统。真实数据扩展应把 `generate_scene` 替换为 GeoTIFF loader，保持任务/技能接口不变。

## 局限

- 32×32 合成场景，无真实传感器噪声、地形、配准误差；
- 无 LLM 参与，技能是确定性程序；
- 技能库较小（约 20 个），成功阈值手工设定；
- 每个任务族只有 8 个 probe，后验保守但仍有噪声；
- 结构特征单独使用与完整模型竞争力相当，论文中如实报告。
