# SkillEvo manuscript

- `skillevo.md` — full Markdown draft (readable, with embedded figures).
- `skillevo.tex` — IEEEtran journal source; figures are PNG for portability.
- `refs.bib` — BibTeX entries used by the LaTeX source.
- `figures/` — architecture, method comparison, reliability, ablation, memory,
  and transferability figures. The data figures are generated by
  `python -m skillevo.report` as SVG and rendered to PNG for the manuscript;
  `architecture.svg` is the source diagram. Any SVG renderer can rebuild the
  PNGs.

## Build

```bash
pdflatex skillevo
bibtex skillevo
pdflatex skillevo
pdflatex skillevo
```

The LaTeX toolchain is not installed in this workspace, so the PDF is not
committed. The Markdown draft and the committed figures contain the same
numbers.

## Reproducing the numbers

```bash
python -m skillevo experiment --seeds 0,1,2 --output experiments
python -m skillevo report
```

`experiments/results.json` is the source of truth. The manuscript
tables are copied from `experiments/REPORT.md` (three seeds, 126
target test tasks).

## Scope

The benchmark is synthetic and diagnostic, not a remote-sensing leaderboard.
The paper explicitly reports that structural compatibility alone is competitive
with the full selector, and that tiered memory mainly improves calibration and
footprint rather than raw success.
